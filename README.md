## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».
Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

Проект реализован **без CSS-фреймворков** и **без полноценной JavaScript-интерактивности**.
JavaScript используется только для открытия/закрытия модального окна и базовой
валидации форм.

## Используемые технологии

- HTML5 (семантическая разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`)
- CSS3:
  - CSS-переменные в `:root`
  - Состояния `:hover`, `:focus-visible`, `:disabled`, `[aria-invalid="true"]`
  - Flexbox и CSS Grid
  - БЭМ-именование классов
  - Позиционирование: `relative`, `absolute`, `sticky`, `fixed`, `z-index`
- Минимальный JavaScript (модальное окно и валидация форм)

## Обязательные страницы

| Страница | Содержание |
|----------|-----------|
| `index.html` | Hero-блок, преимущества, популярные товары, якорные ссылки |
| `catalog.html` | Карточки товаров, фильтры (aside), сетка Grid |
| `product.html` | Изображение, описание, таблица характеристик, отзывы |
| `order.html` | Форма заявки со всеми полями и валидацией |

## Реализованные элементы интерфейса

- кнопки заказа в карточках товаров;
- модальное окно с формой заявки (`<dialog>`);
- поля формы: имя, e-mail, телефон, дата, тема, комментарий, согласие;
- базовая HTML-валидация (`required`, `type="email"`, `pattern`, `minlength`);
- JS-обработка форм и сообщения об успешной отправке;
- таблица характеристик с `caption`, `thead`, `tbody`, `th`, `td`;
- блок отзывов;
- хлебные крошки;
- sticky-фильтры каталога.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- переменные для цветов и скруглений;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- визуальная подсветка ошибочных полей через `aria-invalid`;
- Flexbox (шапка, меню, футер);
- CSS Grid (сетка товаров, макет каталога, детальная страница, контакты);
- БЭМ-именование классов.

## Самостоятельные доработки

1. **Блок отзывов** на странице товара.
2. **Хлебные крошки** на странице товара.
3. **Sticky-фильтры** в каталоге.
4. **Бейджи товаров** через БЭМ-модификаторы: `product-card--hit`, `product-card--discount`, `product-card--new`.
5. **Расширенная таблица характеристик** с `caption`, `thead`, `tbody`.
6. **Форма обратной связи** на странице контактов.
7. **Отдельная форма заявки** на странице `order.html`.
8. **Базовая адаптивность** через media-запросы.
9. **Улучшенная доступность**: `aria-label`, `aria-modal`, `aria-labelledby`.
10. **Подробный README.md** с описанием структуры.
